### What I learned

I used Sass because it was suggested in the "Ideas to Test Yourself" section.  I liked it.  The mixins were useful, and I'm looking forward to using funcitons.

As my css is improving, I'm becoming more aware of how I'd implement the designs in css, so I'm able to plan better.  My design file is a little messy, there's a lot of classes whose names could be improved, and I think the flow of the file is a little awkward, but I think that will improve for my next projects because I'll plan for them better.

Another think I learned is how to make speach bubbles in css by using borders with no content.  

### Continued development
